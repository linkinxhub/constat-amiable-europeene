# Signature de démarrage de test
startup.wav est une composition originale synthétisée : trois sinusoïdes
523,25/659,25/783,99 Hz, départs 0/120/240 ms, enveloppe douce, durée 640 ms,
PCM mono 16 bits à 44,1 kHz. Aucun enregistrement tiers utilisé.
Lecture plafonnée à 35 %, aucune boucle, une tentative par démarrage à froid.
Le choix utilisateur reste prioritaire et le son est désactivé par défaut.
Ambient/mixWithOthers sur iOS, assistanceSonification sans focus sur Android.
Silencieux, DND, Bluetooth et qualité d’écoute à recetter physiquement.
