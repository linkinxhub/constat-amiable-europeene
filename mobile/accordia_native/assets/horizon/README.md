# Horizon hero

Illustration décorative originale générée pour Accordia avec l’outil de création
d’images intégré, le 3 novembre 2026. Aucun document ou véhicule personnel utilisé.
Version WebP 1152×768 optimisée depuis l’original généré ; ne représente ni un
accident réel, ni une consigne de placement du triangle ou de sécurisation.
Les consignes réelles doivent précéder la saisie du constat.

Prompt de production : illustration routière 3D douce et haut de gamme ; deux
voitures compactes bleue/blanche arrêtées après un accrochage léger, route calme,
végétation, petit triangle orange, dominante cobalt #064cec, trait lumineux vers
un document translucide générique ; sans texte, téléphone, interface, logo ni
marque automobile. Référence artistique : colonne Horizon de la planche validée.

L’illustration est exclue de la sémantique Flutter. Tous les libellés restent du
texte natif traduisible. Ce fichier ne constitue pas le logo officiel Accordia.
