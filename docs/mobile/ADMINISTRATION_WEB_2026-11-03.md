3. Enregistrer le brouillon ne distribue rien. Publier la configuration mobile ouvre un récapitulatif ; Confirmer utilise la dernière révision sauvegardée.
4. L’historique peut être filtré. Republier une ancienne version crée une nouvelle révision ; aucun historique n’est effacé.
5. Un conflit ou un refus d’accès conserve les valeurs. Copier une saisie à garder avant de confirmer son abandon/rechargement. Un avertissement de fermeture ne remplace pas une sauvegarde.
